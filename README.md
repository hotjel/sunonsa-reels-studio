# 수논사 릴스 스튜디오

대본별 자막을 편집하고 Premiere에 올릴 **투명 자막 MOV**를 만드는 Windows용 로컬 프로그램입니다.

## 실행

1. Windows에 Python 3.11 이상을 준비합니다.
2. 저장소를 내려받고 `시작.cmd`를 실행합니다. 첫 실행에는 인터넷 연결이 필요합니다.
3. 브라우저에서 대본과 시작·끝 시간을 입력합니다.
4. `프로젝트 저장`으로 편집 가능한 JSON을 보관하고 `투명 자막 MOV 내보내기`를 누릅니다.
5. Premiere에서 촬영 영상은 V1, 자막 MOV는 V2, 별도 음성·효과음은 오디오 트랙에 배치합니다.

프로그램은 `127.0.0.1`에서 실행됩니다. 실행 창을 닫으면 서버가 종료됩니다.

## 자막 편집

- 대본별 글꼴, 크기, 자간(-15~30px), 글자색, 테두리색·두께
- 말풍선·강조·기본 자막과 팝업·흔들림·타이핑·페이드
- 글자 그라데이션의 끝색·방향
- 테두리 빛 번짐의 색·크기·강도
- 궁서·분홍 그라데이션·흰 테두리·노란 빛 번짐을 적용하는 참고 사진 스타일
- 자막 복제, 대본 일괄 입력, SRT 가져오기, 프로젝트 저장·복구

내보내는 영상은 무음 ProRes 4444 MOV 한 개입니다. 촬영 영상은 앱에서 배치를 확인하는 용도이며 자막 MOV에는 포함되지 않습니다.

## 글꼴과 매뉴얼

무료 배포 글꼴은 `assets/fonts`에 원본 파일, 출처와 라이선스를 함께 보관합니다. 궁서·궁서체와 기타 Windows 글꼴은 해당 PC에 설치된 글꼴을 사용하며 원본 글꼴 파일을 재배포하지 않습니다.

## 검증

의존성이 준비된 환경에서 실행합니다.

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

서버를 실행한 상태에서는 저장·복구, 실제 미리보기, 투명도 및 MOV 단독 출력을 검증할 수 있습니다.

```powershell
python tests/http_mov_smoke.py
```

검증 후 `python tests/package_release.py`로 직원 배포용 ZIP을 생성할 수 있습니다. 매뉴얼 재생성에는 ReportLab과 Windows 한국어 글꼴이 필요합니다.

촬영 원본, 개인 프로젝트, 로그, 내보낸 영상, 생성한 ZIP, 의존성 바이너리는 Git 추적에서 제외됩니다.
