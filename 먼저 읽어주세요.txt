수논사 릴스 스튜디오 1.6

시작.cmd를 열고 실행 창을 켜 두세요.
대본마다 시작·끝 시간, 글꼴, 글씨 크기, 자간, 글자색, 테두리색·두께를 설정합니다.
글씨 크기 24~160 / 자간 -15~30px / 테두리 두께 0~12.

그라데이션 · 테두리 빛 번짐을 펼쳐 사용을 켭니다.
- 그라데이션: 글자색이 시작색, 별도 끝색과 방향 0~360°를 설정합니다.
- 방향 0°: 왼쪽→오른쪽 / 90°: 위→아래.
- 빛 번짐: 색, 크기 0~50, 강도 0~100%를 설정합니다.
- 참고 사진 스타일: 궁서, 분홍 그라데이션, 흰 테두리, 노란 빛 번짐.
- 자막 복제 시 새 효과 설정도 함께 복사됩니다.

글꼴: 나눔스퀘어 계열, 배민 도현, 지마켓 산스, 빗썸고딕, 궁서·궁서체.
궁서·궁서체는 Windows 설치 글꼴을 사용하며 배포본에 해당 글꼴 파일은 포함하지 않습니다.

내보내기는 투명 자막 MOV 하나입니다.
1. 프로젝트 저장으로 편집 가능한 JSON을 별도로 보관합니다.
2. 투명 자막 MOV 내보내기를 누릅니다.
3. 완료 후 MOV 받기 또는 내보낸 폴더 열기를 누릅니다.
4. Premiere: 촬영 영상 V1 / captions_alpha.mov V2 / 별도 오디오 A1 등에 배치합니다.
5. 문구·글꼴·그라데이션·빛 번짐을 바꾸려면 앱에서 수정 후 다시 내보냅니다.

MOV: ProRes 4444 투명 배경, 30fps, 무음. 촬영 영상은 자막 MOV에 포함되지 않습니다.
일반 플레이어에서 검게 보일 수 있으니 Premiere에서 영상 위에 놓아 확인하세요.
1080 출력 시 1080×1920, 720 출력 시 720×1280 시퀀스를 사용합니다.
목소리 기준: 캡컷 애덤 1.3배속 / 화낼 때 스포츠엠씨.

직원 매뉴얼: 프로그램 상단의 직원 매뉴얼 또는 output/pdf 폴더.
다른 PC: 압축을 풀고 실행합니다. Windows와 Python 3.11 이상이 필요합니다.
프로젝트 JSON 및 미리보기용 촬영 영상을 보관한 data/media를 함께 옮깁니다.
내보내기 로그는 data/export-logs에 보관합니다.
공식 글꼴 출처·라이선스는 assets/fonts의 NOTICES 및 sources.json을 확인하세요.
